# 开启保险丝后 UU 远程变卡：原因与解决

## 现象

用 UU 远程（网易，进程名 `GameViewer*.exe`）控制装了本工具的电脑。启动 `ChainedProxyFuse.exe` 之后，远程画面明显变卡、延迟变高；关掉保险丝又恢复流畅。

另外还有一个更隐蔽的问题：**保险丝一旦跳闸，UU 也会被一起断开**，远程连不回来，没法点"恢复上网"。

UU 客户端里的代理选项（不使用代理 / 系统代理 / 手动设置）改哪个都没用。

## 原因

### 1. 门禁封掉了 UU 的直连路线

UU 会在每张网卡上各开一个连接通道（真实网卡、sing-box 虚拟网卡各一个），用 P2P 打洞直连控制端。

- **没开保险丝时**：绑在真实网卡上的那条通道不经过 TUN，直接 P2P 直连，所以快。
- **开了保险丝后**：门禁规则把真实网卡上所有公网地址都封了，这条路断了。UU 只能退回到 TUN，整个画面流变成 `电脑 → 前置服务器 → 落地 → 再回到国内 UU 服务器 → 控制端`，绕两次出国，P2P 也打不通，自然卡。

UU 的代理选项之所以没用：TUN 模式是在网络层接管所有流量的，应用层的代理设置决定不了要不要进 TUN。而 v2rayN 设置成"清除系统代理"时，"系统代理"和"不使用代理"效果完全一样；"手动设置"成 v2rayN 的端口反而更糟（UDP 走不通）。

### 2. 为什么不能简单加一条"放行 UU"的防火墙规则

Windows 防火墙里**拦截规则永远优先于放行规则**，所以加一条放行规则是没用的。

改用 Windows 过滤平台（WFP），在一个比 Windows 防火墙优先级更高的子层里给 UU 加一条"硬放行"（`FWPM_FILTER_FLAG_CLEAR_ACTION_RIGHT`），实测：

| 场景 | 硬放行能否盖过防火墙拦截 |
|---|---|
| UU 走真实网卡，被门禁拦 | ✅ 能 |
| UU 走 TUN，被总闸拦 | ❌ 不能 |

查 WFP 状态（`netsh wfp show state`）发现：sing-box 开 `strict_route` 时会建一个**优先级最高（权重 0xFFFF）的子层 `sing-tun`**，给所有走虚拟网卡的连接一个"软放行"。有了这个软放行在前面，后面子层的硬放行就盖不过 Windows 防火墙里总闸的拦截规则了。所以跳闸时，UU 连服务器的那条连接（默认走 TUN）还是会被断开。

## 解决办法（v1.1.0）

1. **门禁**保持不变：仍是 Windows 防火墙规则，封住真实网卡。
2. **总闸**从 Windows 防火墙规则改为本工具自己的 WFP 子层（权重 0xFFFE，紧跟在 sing-box 之后、排在 Windows 防火墙前面）。
3. **放行名单**放进同一个子层：每个 UU 程序一条硬放行，权重高于总闸。
   - 同一子层里高权重的规则先命中，所以 UU 不受总闸影响，不管走 TUN 还是真实网卡。
   - 硬放行又能盖过 Windows 防火墙里的门禁，所以 UU 能从真实网卡 P2P 直连。
4. 规则都是持久的（`FWPM_FILTER_FLAG_PERSISTENT`），重启、工具崩溃都还在，和以前的防火墙规则一样。
5. UU 的安装目录从它的服务注册表 `HKLM\SYSTEM\CurrentControlSet\Services\GameViewerService` 自动找到，放行其中（及 `bin\` 下）的 `GameViewer*.exe`。

### 验证结果

| 检查项 | 结果 |
|---|---|
| 平时：其它程序强行走真实网卡 | 被拦 |
| 平时：UU 远程 | 恢复流畅（P2P 直连） |
| 跳闸：浏览器那条路（TUN） | 被拦 |
| 跳闸：其它程序走真实网卡 | 被拦 |
| 跳闸：UU 的连接 | 30 秒内一直保持 |
| 跳闸：保险丝自己的检测通道 | 正常 |

## 代价与限制

- **UU 的服务器和控制端会看到你的真实 IP**，和不装本工具时一样。对你要保护的网站没有影响，其它软件依然被拦。
- 如果是**落地节点本身掉线**导致跳闸，UU 连服务器那条连接走的是代理链，本来就不通，远程照样会断。这是全局 TUN 模式本身的限制，和保险丝无关。程序退出、v2rayN 关闭、出口 IP 变化这几种跳闸，UU 都能保持连接。
- 不想要这个例外：退出本工具，把 `fuse-config.json` 里的 `"BypassUU":true` 改成 `false` 再启动。
- 其它远程软件（向日葵、ToDesk 等）如果遇到同样的问题，可以把它们的 exe 完整路径加进 `fuse-config.json` 的 `BypassApps`。

## 自己排查类似问题

```bat
:: 看某个程序的连接走的是哪张网卡（本地地址是 172.18.0.1 就是走 TUN）
powershell "Get-NetTCPConnection -OwningProcess (Get-Process GameViewer*).Id -State Established"

:: 导出 WFP 过滤规则和拦截记录（需管理员），查是哪条规则拦的
netsh wfp show state file=state.xml
netsh wfp show netevents file=events.xml
```
