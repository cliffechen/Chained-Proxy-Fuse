# Chained-Proxy-Fuse（链式代理保险丝）

给 [v2rayN](https://github.com/2dust/v2rayN) 链式代理（前置节点 + 落地静态 IP）用户的 Windows 小工具：
**落地 IP 一掉，或者出口 IP 一变，就把整台电脑的网络断掉**，保证网站永远只看到你的落地 IP。

只用 Windows 自带的东西：Windows 防火墙、`curl.exe`、系统自带的 C# 编译器，不需要安装任何运行库。

---

## 它解决什么问题

链式代理（比如 `电脑 → 马来西亚服务器 → 日本静态 IP → 网站`）在**落地掉线的那一刻本身不会漏**：
第二道门一关，整条路就断了，网页只会打不开。

真正会漏出真实 IP 的是这些"空档"：

1. **切换节点 / 重启 v2rayN**：v2rayN 每次切换节点都会先关掉虚拟网卡（TUN）再重开，中间一两秒，所有软件直接用本地宽带出门。
2. **v2rayN 崩溃、被关掉、电脑睡眠唤醒**。
3. **开机时**，浏览器可能比 v2rayN 先联网。
4. **误操作**：切到"直连"，或选了不带落地的节点。
5. **（少见）落地 IP 服务商悄悄换了 IP**。

"发现掉线再断网"来不及——检测总要几秒，泄漏只要一瞬间。所以本工具是**先锁门，再巡逻**。

## 工作原理（打个比方）

把电脑想成一栋房子，上网就是出门：

| 部件 | 做什么 |
|---|---|
| 🚪 **门禁**（一直开着） | 用 Windows 防火墙把真实网卡（Wi-Fi / 网线）封住，只留：通往前置服务器的路、局域网、阿里 DNS。规则写进系统，重启、工具崩溃都还在。虚拟网卡一消失，谁也绕不出去。顺手封掉公网 IPv6。 |
| 👮 **巡逻员**（默认每 5 秒） | 通过代理链问"我现在的 IP 是什么"。不是你的落地 IP → 立刻拉闸；连续 2 次问不通 → 拉闸。也会检查浏览器走的那条路。 |
| ⚡ **总闸** | 拉闸后所有软件都上不了网（局域网除外），只留一条细缝给巡逻员继续检查。用 Windows 自带的 WFP 过滤平台实现，同样重启、崩溃都还在。 |
| 🖥️ **远程控制例外** | UU 远程（网易，`GameViewer*.exe`）不受门禁和总闸限制，见下文。 |
| 🔁 **恢复** | 落地 IP 恢复并稳定约 15 秒后弹提示，**你手动点"恢复上网"**才接回。 |

## 适用条件

- Windows 10 / 11，Windows 防火墙处于开启状态（不能被 360、火绒等安全软件的防火墙接管）。
- v2rayN 7.x，**开启 TUN**（sing-box 负责虚拟网卡，xray 负责链式代理），全局模式。
- 需要管理员权限（改防火墙必须要）。

## 使用方法

1. **编译**：双击 `build.bat`，生成 `ChainedProxyFuse.exe`。
2. **先启动 v2rayN**，选好你的链式节点，确认能正常上网。
3. **双击 `ChainedProxyFuse.exe`**，UAC 弹窗点"是"。
4. 首次运行会弹出"当前出口 IP 是 x.x.x.x 日本"，确认是你的落地 IP 就点"是"；再选择是否开机自动启动（推荐）。
5. 右键托盘圆点 →"模拟泄漏测试"，应显示 **通过**。

### 托盘图标

| 颜色 | 含义 |
|---|---|
| 🟢 绿 | 正常，出口是你的落地 IP |
| 🟡 黄 | 等待 / 检查中（例如 v2rayN 还没启动）。此时门禁仍在，不会漏 |
| 🔴 红 | 已断网，菜单里写明原因 |
| ⚪ 灰 | 已暂停保护，**不受保护** |

### 右键菜单

- **恢复上网**：断网后，落地 IP 恢复稳定才可点。
- **暂停保护**：撤掉所有规则，可以不挂代理正常上网（真实 IP 会暴露）。
- **立即检测 / 模拟泄漏测试 / 重新识别日本 IP / 打开日志 / 开机自动启动**。
- **退出**：退出并撤掉所有防火墙规则。

### UU 远程控制

门禁会封住真实网卡，UU 远程就没法走 P2P 直连，只能绕代理链出国再回来，所以会很卡；跳闸时 UU 还会被一起断开，远程进来点不了"恢复上网"。
因此工具会自动从 UU 的服务找到安装目录，放行其中的 `GameViewer*.exe`：

- UU 可以从真实网卡直连，**网易的服务器和控制端会看到你的真实 IP**（和不装本工具时一样），其它软件不受影响。
- 跳闸时 UU 仍能连上，可以远程点"恢复上网"。但如果是**落地节点本身掉线**，UU 连服务器的那条路（走代理链）本来就不通，照样会断。
- UU 里的代理选项选"不使用代理"即可；TUN 模式下这个选项不影响速度。
- 详细的排查过程和原理见 [docs/uu-remote-lag.md](docs/uu-remote-lag.md)。
- 不想要这个例外：退出本工具，把 `fuse-config.json` 里的 `"BypassUU":true` 改成 `false` 再启动。其它远程软件可以把完整路径加进 `BypassApps`。

### 万一断网恢复不了

双击 **`紧急恢复上网.bat`**（会请求管理员权限），它会结束本工具并删除所有规则。

## 建议的自测

测试时另开一个窗口跑"泄漏监视器"，全程不能出现非落地 IP：

```bat
for /l %i in (0,0,1) do @curl -s -m 2 http://api.ipify.org & echo.
```

1. 把 v2rayN 里落地节点的端口临时改错 → 约 10 秒内变红、所有网站打不开；改回 → 提示恢复 → 点"恢复上网"。
2. 切换节点、重启 v2rayN、结束 `sing-box.exe` → 监视器里不出现真实 IP。
3. 切到不带落地的节点、切到"直连" → 断网，不出现其它 IP。
4. 重启电脑 → v2rayN 启动前无法上网，之后自动变绿。

## 已知限制

- 落地服务商偷偷换 IP 时，最多有一个检测间隔（约 5 秒）的空档。
- 保护开着时，不开 v2rayN 就上不了网——这正是门禁的作用。
- 开着门禁时，在 v2rayN 里给其它节点"测速"会超时，属正常现象。
- 前置服务器的 IP 是从 sing-box 的实际连接里自动学到的；换了前置服务器，如果连不上，先"暂停保护"→ 连上 → "恢复保护"即可学到新地址。
- 检测会走落地 IP 产生少量流量（每次约 1KB，一天约 20MB）。
- 工具只负责"断"，不能让落地 IP 本身不掉线；浏览器指纹、时区等其它关联因素不在范围内。

## 文件说明

| 文件 | 说明 |
|---|---|
| `src/Program.cs` | 主程序（巡逻、托盘、门禁） |
| `src/Wfp.cs` | 总闸和放行名单（WFP） |
| `src/app.manifest` | 要求以管理员身份运行 |
| `build.bat` | 用系统自带 csc.exe 编译 |
| `紧急恢复上网.bat` | 一键删除所有规则 |
| `fuse-config.json`、`fuse.log` | 运行时生成，含你的 IP，**不要分享**（已在 `.gitignore` 中） |
